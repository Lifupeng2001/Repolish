# AI学习心得
机器学习数学基础（程序员纯文本笔记版）
第一部分：核心知识点总结
1. 线性代数：空间与基底的变换
矩阵的本质：矩阵是一个“空间变换函数”。矩阵的“列”（Column），就是变换后的新坐标轴（新基底）。

矩阵乘向量：A * x，本质是用向量 x 里的数字作为权重，去线性组合矩阵 A 的列。

矩阵乘法（C = A * B）：

计算法则：左边取一行，右边取一列，对应相乘再相加。要求 A 的列数等于 B 的行数。

几何本质：把 B 的每一列（基底），用 A 再变换一次。

不可交换性：A * B 不等于 B * A。先旋转再拉伸，不等于先拉伸再旋转。

特殊运算符号：

A ⊙ B（Hadamard积）：形状相同的矩阵，对应位置直接相乘（代码里就是 A * B）。

||x||_2（L2范数）：向量的几何长度，即 sqrt(所有元素的平方和)。用于防止过拟合（L2正则化）。

||x||_1（L1范数）：所有元素绝对值之和。用于制造稀疏矩阵，让权重变成0（L1正则化）。

x · y（点积）：对应相乘再求和，衡量两个向量的相似度（Transformer注意力的核心）。

2. 微积分：寻找最优解的指南针
导数 f'(x) 或 dy/dx：函数在某一点的斜率（变化率）。代码近似：(f(x+dx) - f(x)) / dx。

偏导数 ∂f/∂x：多维函数中，把其他变量当常数，只看某一个变量的变化率。

梯度 ∇f（Nabla）：所有的偏导数拼成的一个向量。它指向函数值“上升最快”的方向。

梯度下降（SGD）：既然梯度指向上坡，那么沿着梯度的反方向走，就是下坡。公式：新权重 = 旧权重 - 学习率 * 梯度。这就是深度学习模型训练的本质。

3. 机器学习高频数学符号
arg max_x f(x)：使 f(x) 取最大值时的“那个 x”（返回的是索引/类别编号），而不是最大值本身。

max_x f(x)：f(x) 的最大数值本身。

softmax(x_i)：把一组任意得分（如 2.0, 1.0）转换成概率分布（如 0.73, 0.27），总和为 1。

f ∘ g（函数复合）：就是代码里的 f(g(x))。

∝（正比于）：A ∝ B 表示 A 等于 B 乘以一个常数。

O(n)（大O记号）：衡量算法的时间或空间复杂度，忽略常数，只看数据规模 n 的增长趋势。

【模块一：线性代数】
题目 1（基础运算与基底）：
已知矩阵 A 有两行，第一行为 [2, 1]，第二行为 [1, 3]。

请问矩阵 A 变换后的新 x 轴和新 y 轴分别是什么？

如果有一个向量 v，第一行为 1，第二行为 2。经过 A 变换后的新坐标是多少？（请使用列的线性组合方式计算）

题目 2（区分乘法）：
已知矩阵 U = [[1, 2], [3, 4]]（第一行1,2；第二行3,4），矩阵 V = [[5, 6], [7, 8]]。

计算 U ⊙ V（Hadamard积）。

计算 U * V（标准矩阵乘法）。

题目 3（几何顺序）：
假设 R 是“顺时针旋转90度”的矩阵，S 是“水平拉伸2倍”的矩阵。如果我们要先拉伸，再旋转，复合矩阵应该写成 RS 还是 SR？

【模块二：微积分】
题目 4（偏导与梯度）：
已知一个损失函数 L(w1, w2) = w1^2 + 3w1w2 + 2*w2^2。

求对 w1 的偏导数。

求对 w2 的偏导数。

写出当前的梯度向量。

题目 5（梯度下降模拟）：
假设某模型只有一个参数 w，损失函数为 L(w) = (w - 4)^2。初始参数 w = 0，学习率（步长） alpha = 0.1。
请手动执行一次梯度下降，计算出更新后的 w 值。（提示：对 w 的导数为 2*(w - 4)）

【模块三：机器学习符号】
题目 6（符号辨析）：

如果用 argmax 函数，返回结果是什么？

如果只问 max 函数，返回结果是什么？

这代表模型认为图片属于第几类？（假设类别索引从0开始）

题目 7（函数复合）：
将数学表达式 h(x) = ReLU(softmax(x)) 翻译成对应的 Python 代码逻辑（可用伪代码）。

第三部分：参考答案与解析
题目 1 解析：

矩阵的列就是新的基底。新 x 轴是第一列 [2, 1]，新 y 轴是第二列 [1, 3]。

向量为 [1, 2]，即 1 份新x轴 + 2 份新y轴。
计算：1 * [2, 1] + 2 * [1, 3] = [2, 1] + [2, 6] = [4, 7]。

题目 2 解析：

U ⊙ V（对应位置相乘）：[[1*5, 2*6], [3*7, 4*8]] = [[5, 12], [21, 32]]。

U * V（行乘列求和）：[[1*5+2*7, 1*6+2*8], [3*5+4*7, 3*6+4*8]] = [[19, 22], [43, 50]]。

题目 3 解析：
写成 SR。因为乘法从右往左执行，先 R（拉伸），再被 S（旋转）作用。

题目 4 解析：

对 w1 求偏导（把 w2 当常数）：2w1 + 3w2。

对 w2 求偏导（把 w1 当常数）：3w1 + 4w2。

梯度向量 = [2w1 + 3w2, 3w1 + 4w2]。

题目 5 解析：
当前 w = 0。

计算当前导数：2 * (0 - 4) = -8。

更新公式：新 w = 旧 w - alpha * 导数 = 0 - 0.1 * (-8) = 0 + 0.8 = 0.8。
（更新后 w=0.8，距离目标值 4 近了一步）。

题目 6 解析：

argmax 返回最大值的索引，即 1。

max 返回最大数值本身，即 0.7。

属于第 1 类。

题目 7 解析：
def h(x):
probs = softmax(x) # 先转概率
return max(0, probs) # 再经过 ReLU 激活
